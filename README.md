# 🍕 Cabocos Bar - Sistema de Pedidos Online

Sistema web responsivo para realização de pedidos de um estabelecimento (Cabocos Bar), com envio direto para o WhatsApp.

------------------------------------------------------------

FUNCIONALIDADES

- Cardápio organizado por categorias (Pizzas, Pastéis, Bebidas, etc)
- Personalização completa de pizzas:
  - Escolha de tamanho (P, M, G)
  - Opção de 1 sabor ou 2 sabores (meio a meio)
  - Seleção de borda
- Carrinho de compras dinâmico
- Cálculo automático do total do pedido
- Promoção automática:
  - Quintas-feiras: pizza G ganha refrigerante de 1L
- Envio do pedido diretamente para o WhatsApp
- Formas de pagamento:
  - Dinheiro
  - Cartão
  - Pix (com validação de comprovante)
- Interface responsiva (mobile first)

------------------------------------------------------------

TECNOLOGIAS UTILIZADAS

- HTML5
- CSS3
- JavaScript (Vanilla)

COMO EXECUTAR O PROJETO

1. Baixe ou clone o repositório:

git clone https://github.com/seu-usuario/cabocos-bar.git

2. Acesse a pasta do projeto:

cd cabocos-bar

3. Abra o arquivo:

index.html

Ou utilize a extensão Live Server no VS Code.

------------------------------------------------------------

COMO FUNCIONA

1. O cliente escolhe a categoria (Pizzas, Pastéis, etc)
2. Seleciona o produto desejado
3. Personaliza (no caso das pizzas)
4. Adiciona ao carrinho
5. Informa os dados de entrega
6. Escolhe a forma de pagamento
7. O pedido é enviado automaticamente para o WhatsApp do estabelecimento

------------------------------------------------------------

OBSERVAÇÕES IMPORTANTES

- O comprovante de pagamento via Pix deve ser enviado manualmente pelo cliente após abrir o WhatsApp
- Sistema desenvolvido com foco em simplicidade, rapidez e usabilidade
